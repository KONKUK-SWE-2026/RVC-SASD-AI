# Event List

| Input/Output Event | Description |
|---|---|
| Obstacle Detection Input | Sensors report obstacle detection for the front, left, and right directions. |
| Dust Detection Input | Sensors report whether dust is detected. |
| Movement Command | The automatic cleaning function directs the RVC to move forward, turn aside left or right, or move backward as required by the detected obstacles. |
| Cleaning Control Command | The automatic cleaning function directs cleaning and mopping, stops cleaning during obstacle handling, and temporarily increases cleaning power when dust is detected. |
