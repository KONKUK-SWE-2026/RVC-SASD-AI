Simulator conventions and limits

  • The web app calls the compiled C11 controller. It does not implement the controller decisions in JavaScript.
  • One C call returns a movement sequence. The simulator advances that sequence one action per tick; it calls C again when the pending sequence is consumed.
  • The C command is “turn aside” without a side choice. For deterministic map motion only, the adapter prefers left when open, otherwise right; this is not a controller rule.
  • The compiled C controller advances the five-tick dust timer on every simulation tick. Effective Boost is shown only while cleaning is active; the timer continues during stopped-cleaning movement actions.
  • Boost power magnitude and left/right turn selection remain abstract.
  • A grid edge stops movement in the simulator. It is not reported as an obstacle sensor input.
